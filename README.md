# kambo-retreat.com

Сайт практик Анастасии Гроо: камбо-ретриты, активация кундалини, обучение.

- `index.html` — вся страница. Расписание — блоки `class="slot"` с `data-date`; прошедшие даты скрываются автоматически.
- Контакты для кнопок записи — объект `CONTACTS` в конце `index.html`.
- `img/` — фото.
